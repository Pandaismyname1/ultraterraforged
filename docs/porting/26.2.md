# 26.1.2 → 26.2

A small hop for build tooling (only version numbers change) and a medium one for code: **124 new compile errors in 29 files** ([census/26.2-new.md](census/26.2-new.md)). Two thirds of them are in the vanilla-mirroring preset data. The surface-rule changes here are a warm-up for 26.3's rewrite, so do them in a way that makes the 26.3 port smaller.

NeoForge `26.2.0.88` is a **stable** build (26.3 is beta-only). If RTF wants one long-lived 26.x target before the 26.3 worldgen rewrite settles, 26.2 is it.

## Other 26.2 notes

- **Structure processors** are an interface with `MapCodec codec()`, and `processBlock` takes a `BlockPos`. RTF doesn't define processors.
- **Features:** `sequence`, `template`, `weighted_random_selector` and speleothem (dripstone) features are new. `RandomFeatureConfiguration`/`WeightedPlacedFeature` are deprecated in favour of `weighted_random_selector`. RTF's tree selection in `PresetConfiguredFeatures` uses `random_selector`: keep it (it still works in 26.2), but 26.3 removes the configuration classes, so moving to `weighted_random_selector` now shrinks the 26.3 diff.
- **`ChatFormatting`** is mostly gutted in favour of `Style.withColor`/`withBold`. RTF uses it in 9 files; the census doesn't flag them, so the constants RTF uses survived (**verify** at runtime: the colours in tooltips and labels).
- **`logoFile` in `neoforge.mods.toml` is deprecated** (use `iconFile` + `bannerFile`).
- **Experimental Vulkan backend:** RTF's GUI doesn't touch GPU APIs directly beyond `DynamicTexture`, so nothing to do.
- **Gradle:** the Fabric 26.2 post recommends 9.5.1.
